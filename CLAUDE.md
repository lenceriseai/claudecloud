# Правила для Claude

## Сохранение файлов

Облачная сессия Claude Code временная: её сервер удаляется после простоя.
Постоянное хранилище — этот GitHub-репозиторий.

- Все файлы, которые создаются для пользователя (документы, скрипты, код,
  заметки, картинки), сохраняй в этот репозиторий, а не во временные папки.
- После каждого законченного куска работы делай commit и push, не дожидаясь
  конца сессии.
- Большие медиафайлы (видео, архивы больше ~50 МБ) не клади в git — предложи
  облачное хранилище (Cloudflare R2 или Supabase Storage).

## Общение

- Пользователь пишет по-русски — отвечай по-русски.
