# Фото города

Кладите сюда свои фото настоящих мест: здания, улицы, перекрёстки, мосты, площади, вывески, общий вид.

Подписывайте файлы так, чтобы было понятно место, например `glavnaya-ploshchad-1.jpg`, `most-cherez-reku-noch.jpg`.

Чем больше фото узнаваемых мест, тем больше игра будет похожа на ваш город.
