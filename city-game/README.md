# city-game: папка разработки

Здесь всё настроено для работы над игрой в Claude Code:

| Файл | Что это |
|---|---|
| `.claude/settings.json` | главная сессия в этой папке работает на **Fable 5.2** (координатор) |
| `.claude/agents/builder.md` | помощник-исполнитель **builder** на **Opus 5.5** |
| `.claude/agents/judge.md` | независимый судья **judge** на **Opus 5.5** |
| `CLAUDE.md` | правила проекта: команда, судейство, где что лежит |
| `refs/` | ваши фото города |

## Как начать на Mac

1. Склонируйте этот репозиторий на Mac (или скачайте) и скопируйте **содержимое** папки проекта Godot (там, где лежит `project.godot`) в эту папку `city-game/`.
   Если ваша игра уже лежит в своём git-репозитории, проще наоборот: скопируйте `.claude/`, `CLAUDE.md`, `refs/` и `.gitignore` отсюда в папку игры.
2. Положите фото города в `refs/`.
3. Откройте Claude Code в этой папке: `cd city-game && claude` (или выберите папку в приложении). Проверьте `/model`: должна быть Fable 5.2. В `/agents` должны быть builder и judge.
4. Заполните анкету из `../prompts/godot-graphics-upgrade-prompt.md` и вставьте главный промт.

## Как переименовать агентов

Поменяйте поле `name:` в файле агента и само имя файла, например `builder.md` → `master.md` и `name: master`. Имя пишется латиницей, маленькими буквами, через дефис.

## Модели

- Fable 5.2 задана полным именем модели, она не сменится сама.
- builder и judge указаны как `opus`: это всегда последняя версия Opus, сейчас Opus 5.5. Чтобы закрепить именно 5.5, замените `model: opus` на полное имя модели.
